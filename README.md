# Min musik

Fristående musikapp (systerapp till Min tablå) för dator och mobil.

**Appen:** https://rydellfilm.github.io/min-musik/

- Tips på liknande musik utifrån favoritartister, grupper, låtar och genrer (Last.fm + valfri AI)
- Spellistor som sparas till Spotify
- Uppspelning direkt från appen: i webbläsaren, på wifi-högtalare via Spotify Connect (t.ex. WiiM Pro Plus) eller Bluetooth

Allt sparas lokalt i webbläsaren. Inga nycklar ligger i repot – de fylls i under Inställningar i appen.

## Spotify-uppsättning
Redirect URI i Spotify Dashboard: `https://rydellfilm.github.io/min-musik/`
